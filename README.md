## Tools

| Tool | Description |
|------|-------------|
| `get_weather` | Current weather for a city (temp, humidity, wind, conditions) |
| `get_forecast` | 5-day forecast at 3-hour intervals |
| `get_weather_by_coords` | Weather by GPS coordinates |

## Quick Start
